# UserTux for Android

UserTux scipts and configs for Android.

## Install in the UserLAnd chroot

```
% cd /tmp/
% wget "https://github.com/nansume/android-usertuxspace/raw/master/scripts/install_usertux.sh"
% /tmp/install_usertux.sh
```
